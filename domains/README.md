# Domains

Geplante Fachdomänen:

- identity
- tenancy
- iam
- customers
- locations
- loyalty
- stamp-cards
- rewards
- vouchers
- orders
- integrations
- wallet
- campaigns
- notifications
- analytics
- billing
- audit

Die konkreten Module werden erst angelegt, wenn ihre Entwicklungsphase startet. Domain-Code darf nicht durch direkte interne Querimporte gekoppelt werden; Kommunikation erfolgt über definierte Contracts/Application Interfaces.

# Apps

Geplante deploybare Anwendungen:

- `merchant-web` – Händlerverwaltung und später POS-nahe Händleroberflächen
- `customer-web` – Mobile-first Endkundenportal
- `admin-web` – Plattform-/Super-Admin
- `api` – NestJS API und autoritative Business-/Security-Schicht
- `worker` – BullMQ Background Worker

Die konkreten App-Projekte werden in R0 schrittweise erzeugt und erst dann mit Framework-Abhängigkeiten versehen.
